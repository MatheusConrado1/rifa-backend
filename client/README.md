# Rifa Frontend

Frontend em React + Vite para autenticar jogadores e jogar a mesa de Rifa via WebSocket.

## Rodando localmente

```bash
npm install
npm run dev
```

## Variaveis de ambiente

Crie um `.env` no `client/` se precisar sobrescrever os defaults:

```bash
VITE_API_BASE_URL=http://localhost:3000
VITE_SOCKET_URL=http://localhost:3000
```
